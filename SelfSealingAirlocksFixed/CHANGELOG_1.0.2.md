# Self-sealing Airlocks (U59 Fix) 1.0.2

- Fixed: Insulated Doors stopped insulating with this mod and passed heat like an ordinary tile.
  The mod replaces the game's door-sealing step, and that step is also where a closed door's
  cells get the door's insulation. The mod now sets it the same way the game does: insulated
  while closed, normal while open.
